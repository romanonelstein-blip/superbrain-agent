# SB-023.1 — Fresh-port launcher fix

This patch fixes the common case where an older Mission Control process on port 8787 remains open and the browser keeps showing stale SB-022 assets.

Changes:
- launcher always changes into its own directory;
- launcher asks the OS for a new free local port;
- the exact URL is opened automatically;
- static and JSON responses are sent with no-store headers;
- UI assets carry an SB-023.1 cache-busting query;
- the page visibly identifies itself as SB-023.1.

No decision-runtime logic was changed. NexusOrchestrator remains canonical.
