# SB-022.1 — Interactive Mission Intake

Status: COMPLETE (local/offline quality gates)

SB-022 showed the canonical Nexus runtime and deterministic demo, but did not expose a UI control for a user-authored mission. SB-022.1 fixes that gap without creating a second final-decision engine.

## Added

- `Ask SuperBrain` textarea and submit button in Mission Control.
- `POST /api/missions/ask` for user-authored missions.
- Live provider bridge selection from configured OpenAI, Anthropic or Gemini credentials.
- Draft specialist responses are displayed separately from the canonical Nexus decision.
- Provider output stays explicitly **unverified** until future source-backed research verifies it.
- Clear provider-setup failure instead of a silent/non-responsive page.
- `.env` loading from the repository root without an extra dependency.
- System status now reports configured provider names only (never key values).
- Master-decision controls in the browser.

## Safety boundary

`NexusOrchestrator` remains the only canonical final-decision engine. Provider text is a draft analysis and is never silently treated as verified evidence.
