# SB-027.1 — Live OSINT launcher fix

## Problem fixed

Windows can execute a `.bat` directly from a ZIP preview. In that situation the
ZIP preview may materialize the BAT without materializing its sibling
`live_osint_smoke_test.py`, producing:

```text
python.exe: can't open file ...\\live_osint_smoke_test.py
```

## Fix

`run-live-osint-test.bat` now:

1. Uses an absolute script path relative to the BAT.
2. Verifies the script exists before starting Python.
3. Detects the ZIP-preview case.
4. Searches common Windows locations for the downloaded SB-027 ZIP.
5. Automatically extracts the ZIP to a temporary recovery directory.
6. Runs the exact packaged `live_osint_smoke_test.py` from the recovered build.
7. Falls back to a clear `Extract All...` instruction if recovery is impossible.

The SuperBrain Python test itself was not replaced or bypassed.
